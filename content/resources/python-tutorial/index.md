## 适合谁

如果你刚开始学 Python，想按章节系统地学习语法、数据结构、函数和模块，可以从这里开始。页面标题标注为 Python 3.14.8 文档，与本站 Python 页面推荐的版本一致。

## 怎么读

:::steps
1. 从目录开始，先读前几章，熟悉解释器和基本语法。
2. 每读一节，就在本机的 Python 中运行示例，并把结果和书中的说明对照。
3. 遇到不熟悉的内置函数或标准库模块，回到官方文档查询对应条目。
:::

## 常见问题

:::details{title="教程版本和我安装的 Python 不一致"}
先在终端运行 `python --version`，查看自己安装的版本。版本不同时，以你安装的版本对应的官方文档为准。
:::

:::details{title="中文译文和英文原文有出入"}
以英文原文为准。遇到疑问时，可以到 docs.python.org 的英文版对应章节核对。
:::
