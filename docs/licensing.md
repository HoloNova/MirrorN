## 适用范围

| 内容 | 默认许可 |
| --- | --- |
| 新站 src、scripts、config、样式、构建及 CI 配置 | MIT |
| 文档中的原创程序代码示例 | MIT |
| 新站原创资源 index.md、原创 sources.json 编排和说明、README／MAIN／DESIGN／PLAN／CONTRIBUTING 与 docs 原创说明 | CC BY 4.0 |

旧项目与 archive 目录已删除，Git 历史中的原始条款与来源不被追溯更改。事实、链接和不受版权保护的内容不因此产生额外权利限制。资源的 tags.license 描述被介绍资源，不代表站内叙述、第三方附件或所有下载地址都采用同一个许可证。上传第三方文件时须在资源正文记录其出处、作者和分发许可；已有字段未引入另一套附件授权 Schema。

## 复用与署名

复用原创文章应保留署名、原文链接和 CC BY 4.0 许可标识；改编或翻译须说明修改。资源页以 authors 显示内容署名，Git 历史保留实际贡献记录。可采用“作者显示名，MirrorN《文章名》，原文 URL，CC BY 4.0；已作某项修改”的署名形式。不需要转载者使用同样的文档或软件许可证，也不将普通收录解释为对商标的授权。

复用新站代码须保留 MIT 版权与许可文本。项目中的第三方原始版权、许可或 NOTICE 不得删除；完整代码源分发仍须保留各依赖的原有条款。

## 贡献与静态产物

提交原创代码意味着按 MIT 贡献，提交原创文档意味着按 CC BY 4.0 贡献；第三方材料须单独明确授权，不将来源不明的内容改标成本站原创。PR 模板要求贡献者确认有权提交，不建设额外授权后台。

每次静态构建从仓库及已锁定依赖生成 `/licenses/mit.txt`、`/licenses/cc-by-4.0.txt`、`/licenses/fuse.txt`、`/licenses/zod.txt`、`/licenses/react.txt`、`/licenses/react-dom.txt`、`/licenses/react-router.txt`，Fontsource 原始 OFL 位于 `/font-licenses/`。关于页及资源页可访问相应许可，产物检查核对完整原始字节；不是仅放一条外部链接。Fuse.js、Zod、React、React DOM 和 React Router 是当前浏览器打包依赖，字体保持各自 OFL；开发工具不冒用本站许可。

以后引入新的客户端依赖或第三方静态文件时，须同步公开原始版权／许可及必要 NOTICE，并扩展产物许可映射。不得以当前许可映射覆盖所有未来依赖。
