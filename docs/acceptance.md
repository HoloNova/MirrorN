# 全项目验收矩阵

> 状态：P0、P1 与 P2 均已获用户确认验收。本次 P2 按用户要求不创建或运行过渡样本测试，收尾仅正式内容校验、类型检查和一次构建，证据见 PLAN；空内容根不代表 C01–C09 的输入矩阵已运行。下表仍是全周期完成条件，不是端到端通过报告。

## 1. 内容与构建

| ID | 操作／输入 | 必须观察到的结果 | 验证方式 |
| --- | --- | --- | --- |
| C01 | 新增有效资源文件包 | 同一注册表生成页面、分类与搜索数据 | 定向集成／产物检查 |
| C02 | 两个目录声明同一 id | 构建失败并指出两个文件，不覆盖其中之一 | 纯逻辑用例 |
| C03 | 非法类别、日期或 checksum | 错误包含文件和字段路径，不生成部分发布产物 | 纯逻辑用例 |
| C04 | Markdown 中包含未知指令、错误参数、原始 HTML／JSX 或不完整指令 | 明确拒绝并定位错误；代码块示例仍只作文字，不执行文档代码 | 解析器定向用例 |
| C05 | 公开文档引用草稿或缺失资源／来源 | 发布校验失败，不静默隐藏引用 | 引用用例 |
| C06 | 资源设为 draft | 页面、分类、索引、sitemap、专属附件全部排除 | 产物检查 |
| C07 | 本地附件缺失、越界或哈希与声明不符 | 构建失败，不复制任意外部文件 | 路径／文件用例 |
| C08 | 文档类资源没有下载入口 | 有有效正文即可发布，不强制填写伪下载 | 契约用例 |
| C09 | 站内链接或锚点不存在 | 发布校验指向具体文档与目标 | 链接检查 |
| C10 | 文件出现在 archive 或测试样本中 | 不进入新站路由、资源统计或搜索索引 | 扫描范围检查 |

## 2. 自定义语法、来源和资源组件

作者写 `::download`／`:::notice` 等 Markdown 指令，站点统一解析和渲染组件。验收必须覆盖指令名→参数校验→引用解析→组件输出链，不接受只演示手写 MDX 标签的实现。

| ID | 操作／输入 | 必须观察到的结果 | 验证方式 |
| --- | --- | --- | --- |
| R01 | 使用八种 sourceType | 文件、网页、仓库、命令和本地附件行为准确 | Resolver 定向验证＋人工点击 |
| R02 | 选择版本／平台／架构后切换来源 | 只切换相同 artifact，不替换成其他版本或封装 | 选择逻辑验证＋人工操作 |
| R03 | 没有匹配产物或所有入口 broken | 显示明确状态，不自动下载其他文件 | 人工验收 |
| R04 | 发布页 URL 传给 Download | 校验拒绝，要求用 SourceList，不伪装文件下载 | 契约用例 |
| R05 | InstallCommand 显示命令 | 复制内容与原文一致，不执行命令；失败可手动选择 | 人工验收 |
| R06 | Checksum、CompatibilityTable、ResourceCard | 数据来自对应引用，不重复维护文本值；缺失引用可定位 | 契约验证＋人工验收 |
| R07 | JavaScript 不可用 | 正文和基本链接仍能使用，选择器有静态替代入口 | 人工验收 |
| R08 | 本地文件内容变化 | 输出地址随摘要变化，数据大小／校验值一致 | 文件与产物验证 |

## 3. UI 人工验收 Todo

不使用 UI 单元测试、Playwright 或 computer-use。由维护者启动本地站点，Agent 提供本次修改涉及的条目，不每次重复整个清单。

### 顶部导航和主题

- [ ] 桌面顶部只有首页、已收录、关于本站三个主要入口；资源页正确标识所在位置。
- [ ] 主导航 Tab 在桌面居中、空间充足时均分，窄屏不出现折叠菜单；不换行，放不下时可触摸横滑、键盘聚焦到每个链接，焦点清晰且整页不横向溢出。
- [ ] 在窄屏直接进入「已收录／关于本站」或缩放窗口后，当前项可见，仍可手动横滑到其他项。
- [ ] 44px 图标按钮依次切换 system、light、dark；名称／提示说明当前及下一模式，刷新保留选择，无 JS 按系统主题显示，存储不可用时仍可切换，字体加载失败仍可阅读。
- [ ] 正文、控件与状态提示对比度足够，不仅靠颜色表达状态。

### 首页

- [ ] 搜索名称、别名和显式拼音能找到正确资源；精确名称优先。
- [ ] 加载、空查询、无结果、索引失败和重试状态不同且清楚。
- [ ] 方向键、Enter、Escape 与清空可用，结果变化不丢输入焦点。
- [ ] 返回首页恢复查询；没有 JS 时可进入已收录目录。
- [ ] 首页动效不阻碍输入，减少动画设置有效。

### 已收录

- [ ] 八分类按固定顺序显示，默认折叠；展开多个分类互不强制关闭。
- [ ] 分类数量等于公开资源数量；空分类有说明。
- [ ] 英文／中文拼音／数字排序符合规范，多音字按 sortKey 修正。
- [ ] 卡片只显示名称、可整卡访问；页面没有搜索框或下载按钮。

### 资源文档

- [ ] 标题、简介、正文、代码、表格和所有八个组件可阅读，无重复 h1。
- [ ] 页面在桌面／平板／手机上不横向溢出，代码与表格内部可滚动。
- [ ] 右目录正确定位和高亮；窄屏折叠到正文顶部；少标题时不留空侧栏。
- [ ] 锚点不被顶栏遮挡，复制失败也有明确反馈。
- [ ] deprecated／archived 显示原因，不自动从目录删除。
- [ ] 来源文案与真实行为一致，跨源切换不会悄悄换版本。
- [ ] 编辑此页与贡献者信息正确，普通链接不依赖客户端路由才能打开。

### 关于和错误页

- [ ] 关于文案与真实定位一致，PR 链接有效且不是 example.com。
- [ ] 无效／下架地址显示 404，并提供首页与目录入口。
