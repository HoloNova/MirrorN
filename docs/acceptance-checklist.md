# 公网人工验收清单

**2026-10-01后台文件索引版尚未发布。** 本轮先验后台功能，不做UI设计或浏览器验收。下面是配套功能接线的待办，发布后才由用户在 <https://mirror.campuslink.vip/> 人工执行；不使用UI自动化测试。

## 后台功能证据

- 采集任务只启用北大。每次服务启动强制刷新，之后每6小时调度，不用过期判断跳过。
- BullMQ/Redis处理任务持久化、重试和恢复；SQLite发布完整有效批次。抓取中断、校验失败、暂存和异常空结果不替换旧数据。
- 查询API只读数据库；搜索、分页、筛选、旧browse/package退出路由均不请求源站。Redis失联不会让数据库查询变成源站请求。
- 验证过真实Debian `bookworm/contrib/amd64` 的302条包记录，两次元数据请求、没有包体下载。没有进行40个仓库的生产全量采集，不能据此宣称全量覆盖。
- 新依赖已定向检查，独立API/采集线程运行包已验证；临时进程结束后停止，生产服务未改。详细边界见 `docs/background-index-implementation-plan.md`。

## 受影响UI与待办（发布后）

- [ ] 首页：只返回已启用的北大资源，生态筛选/搜索与站点页使用同一数据库。没有文件的条目不标“按目录找文件/查找包文件”；没有静态索引兜底，首页测速不恢复。
- [ ] 站点目录与详情：身份资料从数据库API读取；其它站点资料保留，但不启用资源下载。北大资源进入站内页；测速及网络指纹保持原规则。
- [ ] Debian/Ubuntu资源页：显示具体包文件，支持已有文件查询/筛选，不出现`dists/pool`文件夹树、“上一级”或“打开目录”。数据库没有文件时不跳到源站抓取补齐。
- [ ] PyPI资源页：输入包名只检索已经入库的记录。未入库显示空结果，不触发simple索引或原站GET。
- [ ] Node.js/Miniconda/Ubuntu ISO：下载区继续可折叠；通用架构、空版本文件和分页不丢项。所有下载按钮来自数据库具体文件URL，不用目录根代替。
- [ ] 教程区域只占位，不新增教程正文或任务状态说明。
- [ ] 切换系统/架构/版本、搜索和下一页只请求本站API；点击真实文件下载时才访问源站，测速为既有例外。
- [ ] 手机390px、深浅主题检查功能接线没有破坏布局；本轮不重做视觉。

源码与任务结构：`apps/server/src/indexing/`负责源站访问，`db/snapshots.ts`发布批次，`db/fileQueries.ts`查询，Web `lib/resourceApi.ts`只读取项目API。教程旧正文作为未来素材保留，当前不参与文件索引准入。
