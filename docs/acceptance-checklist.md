# 公网人工验收清单

**2026-10-01/02后台文件索引版已发布。** 静态快照 `20261001-201932`，后端为独立API/采集线程运行包。请在 <https://mirror.campuslink.vip/> 手动验收；不使用UI自动化测试。本轮只做功能接线，不重做视觉。

## 后台功能证据

- 采集任务只启用北大。每次服务启动强制刷新，之后每6小时调度，不用过期判断跳过。
- BullMQ/Redis处理任务持久化、重试和恢复；SQLite发布完整有效批次。抓取中断、校验失败、暂存和异常空结果不替换旧数据。
- 查询API只读数据库；搜索、分页、筛选、旧browse/package退出路由均不请求源站。Redis失联不会让数据库查询变成源站请求。
- 生产首轮已发布部分实际包数据，Debian去重文件直链440,740条；公网按包名查`hello`能得到具体`.deb`链接。记录由元数据提取，没有下载包体。磁盘空间限制使采集尚未完成，查不到的包不代表源站不存在。
- PyPI约73万包入口保存到SQLite，BullMQ按小窗口派发，避免大队列耗尽Redis；包入口数不等于已经入库的文件数。待办保留，空结果不联网补齐。
- 新依赖、独立运行包及CI已验证；生产使用私有Redis和SQLite一致性备份。磁盘不足2GiB时自动暂停采集、保留待办，数据库仍可查询。详细边界见 `docs/background-index-implementation-plan.md`。
