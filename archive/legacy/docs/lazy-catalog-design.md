# 按需目录与名称搜索（2026-10-05）

用户确认的本轮范围：首页只有生态／软件搜索；同一身份不按镜像站拆分；站点目录先点击再加载，每页10条，底部标记触发续页；软件页自动选站并直接展示、加载首批下载（用户验收后取消展开加载）；增加节省代理订阅流量的手动开关。现有接口保留，不扩充站点、不改文件识别规则、不代理下载字节，教程继续占位。

## 数据与加载路径

后台仍独占源站抓取与数据库写入。所有页面共用 `lib/resourceApi.ts`，不请求上游目录。

| 用户动作                                 | 请求及返回                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 打开首页／空输入                         | 不请求资源数据                                                                                   |
| 输入生态／软件名称                       | `/api/catalog?q=`，统一身份，每页10条                                                            |
| 进入较宽泛的生态                         | `/api/catalog/ecosystems/:id`，生态身份＋软件分页                                                |
| 打开站点详情                             | `/api/sites/:id`，仅身份及可下载软件总数                                                         |
| 点击加载本站资源／滚到底                 | `/api/catalog/sites/:id?q=&cursor=`，每页10条；筛选在后端完成                                    |
| 打开软件页                               | `/api/catalog/software/:id`，取得身份＋实际有文件的候选站点，随后自动加载首批文件                |
| 旧资源书签                               | `/api/catalog/resources/:id`，映射到同一软件身份，保留所点击站点的偏好                           |
| 选站后自动加载下载区／更改系统架构或版本 | `/api/resources/:id/start`，默认筛选＋最多10个文件，一次完成；默认选站内该平台架构的最新稳定版本 |
| 文件续页                                 | `/api/files?limit=10&cursor=`，不重复请求详情或选项                                              |
| 点击更换历史版本                         | `/api/resources/:id/versions?search=&cursor=`，版本另行搜索、每页10条，不提前传851个历史版本     |

`db/discovery.ts` 只读取可下载软件身份、生态关系、来源及计数，不生成全体版本或文件元数据。SQLite连接内缓存小型身份目录，用 `data_version` 和 `total_changes()` 感知其它连接／本连接更新；一致读事务保证身份与修订号对应。后台更新后重新生成，不在前端保留过期静态清单。目录分页游标绑定筛选、列表实际数据的修订号和一小时期限；后台对相同文件清单重新核对，不使目录游标失效。文件／版本分页仍绑定下载范围的修订，保护具体文件的一致性。409重查首屏，不混合新旧页。

查询固定使用已有的软件→版本→下载联合索引。实测默认SQLite计划会为每个软件重扫整站下载，82个软件的重复计数约256ms；指定已有索引后约20ms。旧详情不再通过 `lastCrawlAt/latestCrawl` 重复生成资源；旧文件／选项接口只做身份存在检查。没有修改SQLite结构或采集发布事务。

Web共用 `usePagedList.ts` 与 `PageEnd.vue`：取消过时请求，换条件清空游标，续页错误保留已有结果并停止自动请求，手动重试；离开页面取消请求、计时器和观察器。没有IntersectionObserver时仍可点击加载更多。

## 搜索语义

首页仅查生态／软件名称、稳定标识和真实同义别名，不查文件名、版本或镜像站。NFKC统一全半角，忽略大小写及常见名称分隔符。准确名称优先，再同义名、完整词、长词前缀／包含；至少5字符才允许一处编辑距离，短词不从无关名称里截取片段。

同一软件按 `softwareId` 合并来源；生态是软件集合，不把每个软件升格成生态。一个生态只有同名软件时仅保留软件入口；宽泛生态进入软件分页。搜索npm未独立收录时返回没有准确匹配，不以Node.js代替。

`data/ecosystem-taxonomy.json` 清除npm／apt／yum／pacman等把相关工具误作生态同义名的记录；`data/software.json` 清除Node.js的JavaScript别名及将Python／Conda当软件同义名的记录。原Miniconda生态身份和关联不变，集合显示名改为Python / Conda，区分Miniconda与Anaconda。没有删后台身份或现有文件。

别名配置属于现有规则摘要输入，因此部署重启会照既有启动机制刷新目录；没有变更模板、文件判定、站点绑定、调度周期或队列规则。

## 站点选择与流量偏好

先筛选实际有文件的候选来源，再使用用户指定／记住的站点。没有手动偏好时，若存在与当前出口指纹一致、仍有效的本机测速，按它选择；无有效测量则稳定选择可用来源，不声称最快、不为打开页面发起新测速。多候选才按需校验出口指纹，单北大来源不额外请求。

下载卡片右上角“节省代理流量”是浏览偏好，记在本机，跨页面及其它标签页一致。开启后仅显示已核实中国大陆的下载主机，位置未知也排除；无候选明确显示空状态，不回退海外、不改用户已记住的站点。当前仅明确登记 `mirrors.pku.edu.cn` 为CN；不按official/university性质猜位置。其它站点接入时需核对具体下载主机及跳转终点。

网页不能关闭系统代理或保证绕过全局代理。开关旁明确提示：全局代理下仍需将下载域名设为直连。没有IP地理库、第三方检测、包体中转或一键修改本机配置。
