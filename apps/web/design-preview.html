恢复与还原

在你的终端执行 
npm config delete registry
执行后会发生什么

用户级 registry 配置被移除，npm 回到其他配置层级或官方默认 Registry。

恢复官方默认源不等于还原你原来的配置。如果之前改过这一项，请用前面的备份文件手动恢复。

5

常见问题

全局安装时出现 EACCES 权限错误

执行 npm install -g 时报 EACCES、permission denied。

不要用 sudo 运行 npm。 用管理员权限执行 npm 会让缓存与全局目录归 root 所有，之后普通用户操作会持续报权限错误。

发布包失败：镜像 Registry 不支持发布

把 Registry 换到镜像后执行 npm publish 报错，或包没有出现在官方仓库。

镜像 Registry 通常只做只读代理，不支持 publish。发布时使用 npm publish --registry https://registry.npmjs.org/。
